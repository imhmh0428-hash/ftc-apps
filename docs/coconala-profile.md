## ポートフォリオ
各アプリを1件ずつ登録します。画像は `docs/portfolio/` にあります（1220×1240px）。
追加画像を登録できる場合は、各アプリの `screenshots/` の画面もあわせて登録してください。

### 1. FocusTimer（集中タイマー）
- **画像:** `docs/portfolio/focustimer.png`
- **説明文:**
```
平日に90分だけ集中するための iPhone タイマーアプリです。

・90分のカウントダウン（円形の進み具合表示）
・スタート／一時停止／リセット
・90分を達成した日を記録し、連続日数を表示

使用技術: Swift / SwiftUI（iOS 17 以降）
デザインからコードまで一人で制作しました。
```

### 2. HabitTracker（習慣トラッカー）
- **画像:** `docs/portfolio/habittracker.png`
- **説明文:**
```
続けたい習慣を毎日チェックして、「続いていること」を見える化するアプリです。

・習慣の追加・削除
・タップで今日の達成をチェック
・直近7日間の記録をドットで表示
・連続日数を表示
・データは端末内に保存

使用技術: Swift / SwiftUI（iOS 17 以降）
デザインからコードまで一人で制作しました。
```

### 3. FinanceTracker（家計簿）
- **画像:** `docs/portfolio/financetracker.png`
- **説明文:**
```
収入・支出を「本業」「副業」に分けて記録できる家計簿アプリです。

・収入／支出、本業／副業を選んで記録（金額・メモ）
・今月の合計を本業・副業ごとに自動計算
・スワイプで記録を削除
・データは端末内に保存

使用技術: Swift / SwiftUI（iOS 17 以降）
デザインからコードまで一人で制作しました。
```

> 画像の推奨サイズは、ポートフォリオ登録画面の表示に合わせて調整してください（作業環境から coconala.com を開けず、確認できていません）。
