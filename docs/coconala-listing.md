### サービス内容
```
「こんなアプリがあったら便利なのに」を、iPhoneアプリの形にします。

■こんな方におすすめ
・自分専用の記録アプリ／タイマーアプリが欲しい
・業務で使うちょっとしたツールをiPhoneで動かしたい
・アイデアを、まず動く形で確かめてみたい
・大手の開発会社に頼むほどの規模ではない

■制作例（自作アプリ）
画像の3本はすべて私が SwiftUI で一から作ったアプリです。

1. FocusTimer（集中タイマー）
　90分の集中タイマー。円形の進み具合表示、一時停止・リセット、
　達成した日の記録と連続日数の表示。

2. HabitTracker（習慣トラッカー）
　習慣の追加・削除、毎日のチェック、続けた日数の表示。

3. FinanceTracker（家計簿）
　収入・支出を「本業」「副業」に分けて記録し、今月の合計を表示。

ソースコードは GitHub で公開しています。
【GitHubのURL（プロフィールに記載）】

■基本料金に含まれるもの
・1〜3画面のiPhoneアプリ
・データは端末内に保存（ログイン・サーバーなし）
・ダークモード／ライトモードどちらかのデザイン
・Xcodeプロジェクト一式（ソースコード）の納品
・納品後14日間の不具合修正（無料）

■進め方
1. 購入前にメッセージで「作りたいアプリ」を教えてください（箇条書きでOK）
2. 画面の構成と機能をまとめた簡単な仕様メモをお送りします
3. 合意できたらご購入 → 制作開始
4. 途中で一度、画面の動画またはスクリーンショットで確認していただきます
5. 修正を反映して納品

■対応環境
・iOS 17 以降
・Swift / SwiftUI / Xcode

■できないこと（基本料金の範囲外）
・ログイン機能、サーバー連携、課金機能
・Androidアプリ
・ゲームアプリ
・既存の有名アプリの完全コピー
→ 内容によってはご相談に乗れますので、まずはメッセージをください。

まずはお気軽に「こんなアプリは作れますか？」とご相談ください。
```
